## 🔬 Hands-On Cybersecurity

I use practical exercises and controlled lab environments to connect cybersecurity theory with real-world concepts.

### Areas of Practice

- **Kali Linux:** Exploring Linux-based security tools and workflows.
- **Metasploitable 2:** Learning about intentionally vulnerable systems in isolated lab environments.
- **Network Reconnaissance:** Practising host discovery, port scanning, and service enumeration.
- **Vulnerability Discovery:** Learning to identify, assess, and document potential weaknesses.
- **Web Application Security:** Exploring web security testing and common vulnerability classes.
- **Security Testing:** Studying exploitation techniques within authorized environments.
- **Security Analysis:** Interpreting findings, assessing potential risks, and considering remediation.

### My Lab Principles

All practical security testing is intended for **ethical, educational, and authorized purposes**.

I prioritize controlled environments, clearly defined testing scopes, responsible disclosure principles, and understanding how identified weaknesses can be addressed.

As I complete practical exercises, I aim to document the methodology, findings, lessons learned, and defensive recommendations.
